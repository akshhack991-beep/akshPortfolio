Professional Profile

I am a Bachelor of Computer Applications (BCA) student at Patna University’s B.N. College in Patna, Bihar. My academic journey focuses on developing foundational competencies in core computer science, programming languages like C, Java, and Python, and modern web technologies including HTML, Vanilla CSS, and JavaScript.

Rather than limiting my studies to textbooks, I firmly believe in learning by building. When studying algorithms or user interfaces, I implement them in code—ranging from front-end website recreations like my Myntra Clone and practical DOM applications like my To-Do List, to terminal utilities like my Weather CLI Project in Python.

I am also familiar with modern developer tooling, utilizing Git for version control, GitHub for hosting and collaboration, and exploring AI-assisted workflows using the Google Antigravity IDE.

Current Development Goals

  • Deepening Core Programming: Strengthening object-oriented design and algorithm proficiency in Java and C to establish strong software development fundamentals.
  • Advancing Front-End Mastery: Refining responsive CSS architecture, accessible component design, and asynchronous JavaScript interactions without over-reliance on heavy libraries.
  • Exploring Backend Frameworks: Expanding my foundational knowledge of Django and Python to construct dynamic full-stack web applications and robust database-backed tools.
  • Active Academic Excellence: Continuously excelling in coursework at B.N. College while building an authentic portfolio of practical projects ahead of my 2028 graduation.
